# zen-retrieval

Trace discovery.ts, code-chunks.ts, code-index.ts, index-service.ts, shared-index-client/server/coordinator/protocol.ts, index-migration.ts and exploration.ts. Preserve service/repository filtering before ranking, current unsaved-buffer checks, ignore/private/realpath restrictions, cancellation and clear partial coverage. Use new Turso, text-embedding-3-small at 768 dimensions for both query and corpus. Changing that contract requires a new index namespace and documented rebuild, never mixed spaces.

Preserve one background owner per OS user, connection-authorized canonical checkout filters, saved-source-only persistence and window-local dirty overlays. Exercise simultaneous startup, reconnect after owner death, duplicate subscribers, registration revocation and legacy-cache retirement without touching personal memory, keys or traces.

Check unchanged chunk reuse, deleted/ignored files, renamed symbols, branch changes, dirty buffers, mismatched dimensions and cancellation before committing stale vectors. Prefer syntax chunks and targeted parent reads over full-file context dumps. Validate callers with references/text search; embeddings are not a dependency graph. Local search failure must not trigger web research. Run code-index, discovery, index-service and workspace-tools tests; measure latency on synthetic fixtures before claiming performance gains. Do not embed a developer's private repository merely to benchmark.
